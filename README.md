# Vitalery

**Vitalery** は、健康寿命を基準に「残りの人生の時間」をリアルタイムで可視化し、日々の選択と向き合うためのSPA（Single Page Application）です。

## コンセプト

寿命という抽象的な概念を直感的な「バッテリー」として表現。
単なるカウントダウンではなく、日常生活の中での何気ない選択（睡眠、運動、過労、ストレス解消など）が「命の消費速度（放電スピード）」をどう変化させるかをローグライク形式でシミュレーションします。

- **リアルタイム表示**: ミリ秒単位でカウントダウンが進み、「今もこの瞬間消費されている」臨場感を演出。
- **健康寿命基準**: 厚生労働省の公的データ（男性72.68歳 / 女性75.38歳）を100%基準として算出。
- **思考の生じる選択肢**: パラメータ変化をあらかじめ見せないことで、日常の迷いやトレードオフを体験。
- **自然なUI**: 自身の健康や時間と静かに向き合える、洗練されたライトトーンデザインを採用。

## テクノロジー

- **Runtime / Package Manager**: Deno
- **Framework**: React (TypeScript)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Deployment**: GitHub Pages (via GitHub Actions)
